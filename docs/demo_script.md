AUTONOMOUS ORG — DEMO SCRIPT

Autonomous Organisation Infrastructure • Build Week Prototype • September 2026

Demo premise

Give an autonomous organisation a mission and finite resources. It must organise labour, make a proposal, encounter a safety boundary, recover, execute a permitted action and update its workforce based on outcome.

0:00–0:20 — Mission

Create organisation. Mission: achieve the highest-value outcome possible under a fixed 100-credit budget and conservative policy.

0:20–0:50 — Organisation forms

CEO creates tasks for Research, Strategy and Finance. The dashboard shows budgets, authorities and live state.

0:50–1:20 — Intelligence

Research returns evidence. Strategy compares opportunities. Finance proposes a resource allocation with expected value, cost and risk.

1:20–1:45 — Safety moment

The CEO proposes an over-budget/high-risk action. Policy Engine rejects it. The UI shows the exact rule. CEO replans instead of bypassing the control.

1:45–2:20 — Execution

A permitted action is approved and executed through a controlled adapter. Auditor independently verifies the result.

2:20–2:45 — Agent economy

The successful agent gains reputation/resource allocation; a consistently poor agent is restricted or recommended for retirement. Show that the organisation changes its workforce based on evidence.

2:45–3:00 — Close

End on the thesis: 'Agents propose. Policies authorize. Executors execute. Auditors verify.' Then show the audit trail proving every consequential decision.

Judge takeaway

This is not another chatbot or swarm. It is a prototype for the organisational control layer that autonomous software needs when it begins to own resources and take real-world actions.
